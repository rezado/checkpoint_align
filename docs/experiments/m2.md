# M2 controlled-native validation

This directory supplies the executable dynamic-occurrence evidence missing
from the static DWARF catalog smoke check.  It builds one short marker workload
twice: `A-O0` is rerun for identity evidence, while `B-O2-inserted` adds one
known event.  The running binaries emit their executed marker entry PCs and
logical workload icounts; `dwarf_source.py` resolves those PCs through each
build's own catalog and assigns zero-based local occurrences.

Run the complete experiment with:

```sh
python3 scripts/m2/run_controlled_native.py
```

The derived artifacts are written below `data/results/m2/results/`: build/run
manifests, ELF files, full catalogs, raw PC observations, occurrence traces,
and `validation-summary.json`.  The summary checks exact A-to-A replay, exact
global alignment across the inserted B event, and typed rejection of an
equal-score repeated phase.

This is a controlled native E0/E1-style input, not a held-out SPEC result.
The current SPEC suite has static DWARF and BBV artifacts but no independent
complete runtime occurrence trace, so its precision and coverage remain
unreported and M3 remains candidate-only.

`run_libquantum_qemu.py` adds a real workload capability check using the
supplied A/B `libquantum` ELF files and the identical short input `20 1`:

```sh
python3 scripts/m2/run_libquantum_qemu.py
```

QEMU's full basic-block logs are streamed into a four-function entry filter
and deleted when extraction finishes.  Only the sparse occurrence traces,
selected anchors, output, full-catalog hashes, and alignment summary are retained.  The observed
positions are exact and the functional outputs agree, but these workload
anchors are symbol-only in the supplied ELFs, so the confidence ceiling is
`L`.  This check does not validate the reference-input shifted SimPoints.

After regenerating the controlled and real-workload evidence, aggregate the
milestone state with:

```sh
python3 scripts/m2/summarize_m2.py
```

`validation-summary.json` keeps static catalog coverage, controlled M-level
evidence, real L-level evidence, held-out H/M metrics, and the M3 shifted gate
separate.  The milestone remains `partial` until the missing independent
real-workload H/M trace and reference-input shifted validation exist.
